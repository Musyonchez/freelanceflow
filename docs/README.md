# FreelanceFlow — System Design Documentation

**FreelanceFlow** is an Android application that gives remote freelancers one place to manage clients, projects, time, multi-currency invoicing, expenses, and tax deductions — expanded from the original brief ("Multi-Currency Invoice & Expense Generator") into a full freelance business-management platform.

This folder plans the system from problem statement through deployment. Read the documents in order — each builds on the one before it.
